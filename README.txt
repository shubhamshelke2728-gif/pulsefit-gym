# PulseFit Gym — SEO Assignment Website

A responsive static website created for a Digital Marketing & Social Media SEO assignment.

Files:
- index.html — main website
- assets/style.css — responsive design
- assets/script.js — mobile menu, forms and membership/trial interactions
- assets/favicon.svg — favicon
- robots.txt — crawler instructions
- sitemap.xml — sitemap template

Before publishing, replace example.com in index.html, robots.txt and sitemap.xml with the real published URL.
